## How this seed was made

`routes/web.php` contains 142 literal GET declarations in this snapshot: 110 under the `admin` group and 32 outside it. [The route seed](page_closure/route_seed_2026-09-26.csv) records source line, declared path/name, area and an initial page-candidate/supporting-flow distinction. Every entry starts OPEN. The repository also has 227 Blade views and 95 test files, but neither number counts independent pages or demonstrates browser acceptance.

The CSV is static source discovery. It excludes routes generated by `Auth::routes()`, conditional modals and tabs, POST/PATCH/DELETE mutations, the Paymob callback, Livewire actions, menu visibility, and middleware-resolved permission behavior. Some GET declarations are exports, redirects or lookups rather than pages. The framework-route reconciliation below closes the *registered route* gap, but navigation, role-specific workspaces and conditional UI still require inspection. Do not mark the page inventory complete on route counts alone.

## High-impact findings carried into page review

- Storefront visual clarity is a major redesign target; the owner rated its current presentation below the product's functional strength. Inspect content density, hierarchy, trust and useful help across every customer route.
- Bilingual leakage, RTL and mobile acceptance remain open; route access and translation-key tests do not prove rendered quality.
- POS live mutation, focus and scroll preservation require actual browser checks. Growth and Branding need hierarchy and long-form action-placement review. Permissions is reported as long and mixed-language.
- The source audit also records an unbounded customer-statement read, an incomplete CSV import execution path, and Paymob E2E/restore/credential evidence gaps. Their page and release gates remain separate.
- The route reconciliation exposed public ping responses that included environment metadata and unconditional local-boot tracing. The shared-source fix is GF-13 in the [Global Foundation Audit](GLOBAL_FOUNDATION_AUDIT_2026-09-26.md); verify its branch-head CI and QAS separately.
- Static route names in the Admin sidebar/topbar, Storefront shell and account navigation all matched registered names (45/11/18/6 distinct per file). Their destinations still require behavior review: GF-14 fixes Storefront header fragment links that went nowhere off Home or when their Home sections were disabled. This is source work pending branch-head CI/QAS, not a claim that all navigation variants were inspected.
