## Execution rule

Running a case creates a linked evidence entry; **never overwrite a historical PASS** with a generic new run. For this seed ledger, NEW CASES = 98 (78 journey + 10 E2E + 10 cross-cutting). A case marked BLOCKED is not a failure, nor a pass; a feature not in approved scope is never silently excluded. Cases with different decisive business-policy, role, or state branches need subcases with child IDs, not one checkbox covering multiple untested actions.
